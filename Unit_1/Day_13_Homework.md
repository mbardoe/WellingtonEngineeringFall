# Homework: Version Control with a Spinner

In class you learned about **versions, branching, and merging** in OnShape.  
Now you will practice those skills by making design changes to a spinner.

---

## Step 1: Create a Version of the Base Spinner
- Open the spinner file that your teacher provided.  
- In the **Versions and History** panel (left side), create a **Version** called `Base Spinner`.  
- This version is your starting point for all branches.

---

## Step 2: Make Two Branches
- From `Base Spinner`, create **two separate branches**:
  - Branch A  
  - Branch B  
- Each branch should be different, and both should start from the same `Base Spinner` version.

---

## Step 3: Modify Each Branch
- Open **Branch A** and make at least one noticeable change.  
  - Example: change the size of the center hole, change the arm length, or add cutouts.  
- Open **Branch B** and make a *different* noticeable change.  
  - Example: fillet the edges, change the thickness, or add text.  

---

## Step 4: Merge One Branch
- Choose the branch you like best.  
- Use the **Merge tool** to merge that branch back into the **Main** line of the design.  
- Confirm in the history tree that one branch is merged into Main, while the other remains separate.

---

## Step 5: Reflection
Write a short explanation (5–6 sentences) where you answer:
- What change did you make in Branch A?  
- What change did you make in Branch B?  
- Which branch did you merge, and why?  
- How might branching and merging be useful in real engineering work?  

---

## Deliverable
- Your OnShape document showing:
  - A version called `Base Spinner`  
  - Two branches created from that version  
  - One branch merged into Main  
- A short written reflection (paper, Google Doc, or OnShape Notes).  

---

## Challenge (Optional)
- Create a **third branch** with a completely different idea and independent idea. Try merging that new 
version into the main as well.
