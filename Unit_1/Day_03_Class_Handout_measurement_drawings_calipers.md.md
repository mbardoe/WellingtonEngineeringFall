# Engineering CAD and Design Resource File Plan, 2026-27

This document maps every Markdown resource from the 2025-26 course archive to the revised 29-meeting Term 1 plan for 2026-27.

## Naming convention

- Class resources: `Day_##_Class_Handout_Topic.md`
- Homework: `Day_##_Homework_Topic.md`
- For a class handout, the day number is the day on which students use it.
- For homework, the day number is the day on which it is due at the start of class.
- Files marked **Archive** should be moved out of the active course folders but retained in a `2025-26_archive` folder.
- Files marked **Merge and retire** contribute material to a new resource; the original file should be archived after the combined resource is completed.
